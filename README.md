# Dialdex

A speed dial for people with too many speed dials.

Dialdex replaces the new tab page in Chromium-based browsers and Firefox. It is made for large collections:
grouped dials, tags with automatic suggestions, a fast command palette and a local full-text index.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md).

## Principles

- Local first: your data stays in your browser. No accounts, no telemetry, no ads.
- One codebase for Chrome and Firefox.
- Full export to an open JSON format at any time.
